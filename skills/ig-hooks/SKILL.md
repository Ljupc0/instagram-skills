# Audience-specific Reel hooks

Read [references/profile-contract.md](references/profile-contract.md) before this workflow. When creating or repairing a brief, use [references/profile-template.md](references/profile-template.md).

## Workflow

Read references/hook-formulas.md. Identify the intended viewer, specific tension, verified payoff and format. Select varied mechanisms, not synonym swaps. Unless a count is requested, offer six hooks with spoken line, matching opening visual and the promise the content must fulfill.
Reject fake urgency, invented statistics, unsupported superlatives and promises the content cannot deliver. Do not call a pattern proven without profile evidence. Recommend two variants to test with a comparable body. Hand the selected hook to ig-reel-script when a full script is requested.

## Improvement responsibility

Start from the selected audience problem and experiment. Preserve the profile voice and character role. Review candidate hooks for specific payoff and evidence before selecting; a provocative sentence without a useful body is not ready. Keep first-frame direction consistent with approved brand references. Report alternatives as hypotheses, not guaranteed attention.
