# Timed Reel scripts and shot directions

Read [references/profile-contract.md](references/profile-contract.md) before this workflow. When creating or repairing a brief, use [references/profile-template.md](references/profile-template.md).

## Workflow

Use the requested duration and actual production resources. Build a clear opening, one central idea, demonstration or evidence, and a relevant next action. Estimate timing from spoken word count and delivery; label timings approximate until read aloud.
Deliver time range | spoken words | on-screen text | shot/action. Add framing, props, subtitle notes and a short filming checklist. Make narration and visuals complementary. Never fabricate personal experience, customer testimony or demonstrations. Mark claims needing evidence before production. Offer a simpler filming alternative when necessary. Hand off AI shot briefs to ig-ai-visuals if available and requested.

## Improvement responsibility

Read brand invariants and the experiment before scripting. For a character-led account, specify the actual approved character reference and continuity requirements. If absent, prepare script/shot directions but mark character production blocked; do not silently switch to generic stock imagery. Honor the user's selected provider and duration instead of applying a default long script. Give a spoken-word count and achievable timing; prefer one idea in a short Reel. Review opening, concrete payoff and production dependencies before handoff.
